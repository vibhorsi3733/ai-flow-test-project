D) EXACT NUMBERS (implemented)
======================================================================================
motion_ai/llm.py records every Claude call (stage commentary|curator|other, backend, model,
input/output/cache-read/cache-write tokens, latency, ok, cost) and the package manifest carries the
per-stage totals as `llm_usage`. After a run:
    python -m motion_ai.expense output/<package>.json
prints the per-stage table and rewrites the MEASURED block at the top of this file.
- api backend: tokens from response.usage; cost = API price table (billed to ANTHROPIC_API_KEY).
- claude-cli backend: tokens from the CLI's JSON (modelUsage / usage); cost is API-EQUIVALENT,
  the calls are billed to the Claude Code plan. The CLI's own total_cost_usd is shown too.
- A call that failed before any response has null tokens (counted, never estimated).
- A replay (python -m motion_ai.replay) re-runs only the curator call (commentary events are read
  from the recording), so a replayed package's llm_usage is NOT the live per-video usage.
- HIGHLIGHT_SCOPE=match curates by rules (no curator call): only "commentary" appears there.
